1) Have Foxglove installed
2) Run rtabmapfox in code terminal
3) Go to Foxglove
4) Click on "Open Connection"
5) Paste in ws://localhost:8080 for the Websocket URL
6) Go to the topics tab and make sure you can see all necessary topics
    You can also verify by running ros2 topic list in vscode terminal to see if topics match
7) Open necessary tabs, explore, set up a good Foxglove layout to view robot odometry and sensor data
